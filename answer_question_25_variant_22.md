# Контрольный вопрос №25

## Вариант 22

### Вопрос

Как в PDO получить количество строк, затронутых последним запросом (UPDATE, DELETE)? Какой метод для этого используется?

### Ответ

В PDO количество строк, затронутых последним SQL-запросом UPDATE, DELETE или INSERT, можно получить с помощью метода rowCount(). Данный метод вызывается у объекта PDOStatement, который создаётся после выполнения подготовленного запроса.

Метод rowCount() возвращает целое число — количество строк, которые были изменены, удалены или добавлены в результате выполнения SQL-команды. Это позволяет проверить успешность выполнения операции и убедиться, что нужные данные действительно были изменены.

Пример:

$stmt = $pdo->prepare(
    "UPDATE clients
     SET full_name = ?
     WHERE client_id = ?"
);

$stmt->execute([
    'Иван Петров',
    1
]);

$count = $stmt->rowCount();

echo "Изменено строк: " . $count;
