# Online Booking DB Variant 22

## Описание проекта

Данный проект представляет собой систему онлайн-записи
в центр профориентации на тестирование и консультацию.

База данных разработана на MySQL и включает хранение
информации о клиентах, психологах, тестах,
анкетировании, рекомендациях профессий
и записях на консультации.

Проект выполнен в рамках практической работы
по дисциплине «Проектирование и разработка
информационных систем».

Вариант: 22

---

## Используемые технологии

- MySQL 8
- PHP 8
- PDO
- Git
- GitHub

---

## Структура проекта

sql/ — SQL-скрипты базы данных.

src/ — PHP-классы уровня доступа к данным (DAL).

docs/ — отчёт и скриншоты выполнения запросов.

diagrams/ — ER-диаграмма базы данных.

demo.php — демонстрация работы PDO и репозиториев.

---

## Содержимое папки sql

schema.sql — создание базы данных, таблиц,
индексов и ограничений.

inserts.sql — заполнение таблиц тестовыми данными.

queries.sql — SQL-запросы по варианту.

constraints_test.sql — проверка ограничений
целостности базы данных.
